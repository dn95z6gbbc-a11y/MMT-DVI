# MMT ДВИ

Прототип приложения для подготовки абитуриентов к поступлению на направления журналистики и к дополнительным вступительным испытаниям (ДВИ).

## Сейчас

- Интерактивный прототип: v0.4
- Главная навигация: Главная / Вузы / Подготовка / Портфолио / Профиль
- Работает возврат на предыдущий экран
- Тестовый вуз: СПбГИКиТ
- Карточка вуза разделена на Поступление / ДВИ / Подготовку
- Добавлен расчёт по реальным баллам ЕГЭ без выдачи гарантии поступления
- Добавлен полный учебный цикл: урок → пример → микроупражнение → полевое задание → сдача → разбор по критериям → исправление → повторная сдача → изменение прогресса
- Прогресс, чек-листы, состояние работы, календарь и пользовательские работы в портфолио сохраняются локально в браузере демо
- Портфолио можно пополнять, а отдельный экран показывает логику сборки творческой папки под СПбГИКиТ
- Календарные события открываются как действия: что сделать, отметить выполненным, включить напоминание
- Добавлен сценарий выхода на стажировку и мастер персонализированного письма в редакцию

## Статус

Это интерактивный прототип. Некоторые даты, проценты готовности, результаты и часть интерфейсных текстов демонстрационные и не должны использоваться как актуальная информация о поступлении. В итоговом продукте официальные данные вузов будут храниться по годам с датой проверки и источником.
