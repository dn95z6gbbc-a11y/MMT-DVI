# MMT ДВИ

Интерактивный прототип приложения для подготовки абитуриентов к поступлению на направления журналистики и к дополнительным вступительным испытаниям (ДВИ).

## Сейчас

- Версия прототипа: v0.7.1
- Три архитектурно разные тестовые модели вузов: СПбГИКиТ, МПГУ и РАНХиГС
- СПбГИКиТ показывает модель с письменным испытанием, коллоквиумом и портфолио
- МПГУ показывает модель творческого текста; официальные цифры и даты не публикуются до отдельной проверки конкретной приёмной кампании
- Для МПГУ используется неофициальный пример билета от 18 июля 2024 года из материалов ученицы. Он не помечается как официальный документ МПГУ; сама фотография в приложение не публикуется
- По примеру МПГУ доступны четыре разные темы, выбор темы, формулировка замысла, начало текста и случайная тема; методические рекомендации MMT отделены от пользовательского источника
- РАНХиГС добавлен на основании загруженной программы ДВИ лета 2026 для 42.03.02 Журналистика: письменный тест, 100-балльная шкала, минимум 60 баллов, 40 вопросов и три блока с весами 2 / 3 / 4 балла
- В пользовательском интерфейсе программа РАНХиГС маркируется по сезону экзамена — «лето 2026». Упоминание 2026/27 учебного года внутри документа относится к правилам приёма и не используется как название кампании в приложении
- Для РАНХиГС создан отдельный план подготовки по трём блокам, MMT мини-пробник, задание на сопоставление и банк ошибок. Тренировочные вопросы явно не выдаются за реальные вопросы РАНХиГС
- В РАНХиГС перенесён список рекомендуемой литературы из программы ДВИ
- Первый углублённый учебный модуль — «Новости»: шесть вопросов, лид, перевёрнутая пирамида, ядро / детали / бэкграунд, интерактивные упражнения, самостоятельная новость, демо-разбор и повторная сдача
- Добавлен единый центр «Пробные ДВИ» для трёх выбранных моделей вузов
- Добавлен экран «Мои слабые места»: он не выдаёт фиктивные оценки качества, а использует только выполненные действия, ошибки тренажёров и незакрытые этапы
- После тренировок приложение может собрать ближайший маршрут из незакрытых действий: пробник → разбор → следующая тренировка
- Добавлена история открытия пробных режимов
- На Главной появился переход к диагностике текущего маршрута
- Экран «Мои вузы» различает изучение вуза и добавление его в персональный план
- На Главной есть блок «Продолжить с места остановки» с объяснением, почему предлагается именно это действие
- Добавлена история устных ответов: текстовые попытки можно сохранять и сравнивать; голосовая запись заложена как механика для Android-версии
- Стажировка получила отдельный трекер обращений в редакции
- Вузовская подготовка запускается только после добавления вуза в личный план; до этого можно изучать требования и смотреть демо
- Авторизация в интерфейсе показана как будущий набор вариантов: телефон / VK / e-mail / Telegram
- В профиле есть отдельный вход в индивидуальную подготовку
- В блок «Об авторе» добавлены фотография Олега Мушкова, расширенная профессиональная биография и шесть заготовок видеоотзывов: Злата (Пенза), Кирилл (Ростов), Эльвира (Самара), Настя (Тобольск), Женя (Москва), Маша (Краснодар)
- Портфолио развивается в двух направлениях: хранение работ + рекомендации по оформлению итоговой творческой папки

## Статус

Это прототип. Содержание тестовых упражнений, пробников и критериев ещё будет отдельно дорабатываться. Некоторые даты, проценты готовности, результаты и интерфейсные данные демонстрационные и не должны использоваться как актуальная информация о поступлении. Учебные демо-оценки показывают механику будущего интерфейса, а не реальную проверку работы.

## Следующая основная версия: v0.8

1. Модуль «Актуальная повестка»: неделя / месяц / важные темы для абитуриента
2. Для каждого события — короткое объяснение «что произошло / почему важно / какие стороны есть / что стоит проверить перед использованием»
3. Мини-тесты по повестке и личный список пропущенных тем
4. Практика применения события: пример для эссе, вопрос для устного ответа, возможный ход для творческого текста
5. Связь повестки с выбранными вузами: разные рекомендации для СПбГИКиТ, МПГУ и РАНХиГС
6. Повестка должна быть отделена от новостной ленты: это учебный отбор, а не бесконечный поток новостей
7. После этого — более содержательное сравнение устных попыток и углубление всех пробников реальным учебным содержанием
