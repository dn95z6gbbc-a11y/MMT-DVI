# MMT ДВИ

Интерактивный прототип приложения для подготовки абитуриентов к поступлению на направления журналистики и к дополнительным вступительным испытаниям (ДВИ).

## Сейчас

- Версия прототипа: v0.12.5
- Десять моделей вузов: СПбГИКиТ, МПГУ, РАНХиГС, ГИТР, МГИК, НГУ, ТюмГУ, УрФУ, Московский Политех и ВГУ
- Единый каталог, сравнение, личный план, динамическая Главная и календарь
- База MMT, медиасреда/повестка, письменные и устные тренажёры, симуляции собеседования
- Портфолио 2.0 и стажировка 2.0
- v0.12.x — техническая стабилизация, расширение официального вузовского каркаса и подготовка к большому содержательному блоку

## v0.10 — инфраструктура вузов

Введён единый реестр `MMT_UNIVERSITIES`. Каталог, сравнение, Главная и календарь читают данные из одной модели: город, программа, кампания, статус данных, источник, форматы ДВИ, портфолио, бюджет/стоимость при наличии, состояние «в плане» и календарные требования.

Формальная информация не переносится автоматически между приёмными кампаниями. Если новая дата, стоимость, число мест или проходной балл не подтверждены, поле остаётся пустым / «не внесено».

## v0.11 — портфолио и стажировка 2.0

Портфолио стало единым реестром работ. Для каждой работы можно хранить название, жанр, тип, статус публикации, редакцию/площадку, ссылку, подтверждение и дату. Работы затем сопоставляются с вузами из личного плана без выдуманных процентов соответствия.

Стажировка связана с медиасредой: выбрать редакцию → изучить её → подготовить персональное обращение → приложить портфолио → зафиксировать статус ответа.

## v0.12.x — стабилизация

### Нижняя навигация

После воспроизводимого Android-багa с нативными `<select>` системные выпадающие списки в прототипе заменены на собственные раскрывающиеся списки внутри страницы. Они не открывают Android native picker и не меняют viewport.

Нижняя навигация создаётся отдельным системным слоем и остаётся доступной на вложенных экранах.

Для тестов используется `fresh.html`, который загружает `index.html`, `app.js` и `styles.css` с обходом браузерного кэша.

### v0.12.4 — санитарная чистка UI

Новые учебные функции намеренно не добавлялись.

Сделано:
- старые `search`, `picker`, `results` перенаправляются в единый каталог вузов;
- старые `portfolio`, `portfolioAdd`, `match` перенаправляются в Портфолио 2.0;
- старые `internship`, `letter` перенаправляются в Стажировку 2.0;
- устаревшие экраны остаются только как технический слой миграции и больше не показываются пользователю;
- убраны старые статические виджеты Главной с архивной датой и демонстрационной «ближайшей целью», которые дублировали новый диспетчер;
- профиль больше не выдаёт старые жёстко прописанные город и число вузов за данные пользователя;
- пустые динамические контейнеры получают понятный empty-state;
- чистые кнопки-заглушки, которые только показывали «сделаем позже», превращаются в честные неактивные состояния;
- у полей нового портфолио добавлены пояснения;
- фиктивная загрузка файла в веб-прототипе заменена пояснением, что сейчас можно сохранить ссылку;
- видеоотзывы без загруженного видео больше не выглядят как работающие кнопки;
- добавлен runtime-аудит `MMT_SANITATION_AUDIT` для отсутствующих маршрутов и пустых визуальных блоков.

### v0.12.5 — ещё шесть вузов

В общий реестр добавлены МГИК, НГУ, ТюмГУ, УрФУ, Московский Политех и ВГУ. Для каждого заведён собственный экран официального каркаса, который отделён от будущей методики MMT.

Структурно сохраняются не только названия форматов, но и различия модели экзамена:
- МГИК: письменная работа + коллоквиум/самопрезентация + портфолио;
- НГУ: эссе + анализ текста + вопросы по журналистике + портфолио;
- ТюмГУ: эссе, затем на выбор портфолио или собеседование;
- УрФУ: обязательное собеседование + необязательное портфолио;
- Московский Политех: собеседование по современной журналистике и актуальной повестке;
- ВГУ: обязательное эссе + обязательное собеседование, публикации могут дать бонус внутри второго тура.

У новых моделей сохранены версия/дата источника. Если присланный документ утверждён раньше 2026 года, интерфейс показывает это отдельно и не выдаёт старую дату документа за новое утверждение. Для УрФУ отдельно зафиксирована внутренняя нестыковка источника: заявлено до 50 баллов за портфолио, а перечисленные в доступном тексте критерии суммируются до 40; это не исправляется без дополнительной проверки.

Каталог теперь строит список городов из реестра автоматически и показывает 10 моделей.

## Принцип данных

- МПГУ: примеры, полученные от ученицы, не маркируются как официальный источник.
- РАНХиГС: программа ДВИ лета 2026; банк тренировок ещё требует содержательной ревизии.
- ГИТР: используется загруженная программа ДВИ 2026.
- Новые шесть вузов: официальный каркас строится только по присланным пользователем программам; глубокие тренажёры пока не добавляются.
- Архивные даты 2026 не считаются датами следующей кампании.

## Следующий этап

Сначала короткий тест v0.12.5: каталог → карточки новых вузов → сравнение → добавление в план → Главная/календарь. После этого интерфейс замораживается по крупным функциям и начинается большой содержательный блок — пошаговая ревизия учебного ядра, заданий, критериев и вузовских тренажёров.

Android-разработка начинается после стабилизации ключевых сценариев и содержания.
