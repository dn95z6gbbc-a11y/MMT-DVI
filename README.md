# MMT ДВИ

Прототип приложения для подготовки абитуриентов к поступлению на направления журналистики и к дополнительным вступительным испытаниям (ДВИ).

## Сейчас

- Визуальный прототип: v0.3
- Главная навигация: Главная / Вузы / Подготовка / Портфолио / Профиль
- Работает возврат на предыдущий экран
- Тестовый вуз: СПбГИКиТ
- Реализованы демонстрационные сценарии: выбор и подбор вуза, карточка программы, регистрация/профиль, персональная главная, база MMT, урок, полевое задание, сдача и разбор работы, навыки ДВИ, вузовская подготовка, пробный экзамен, портфолио, календарь и страница автора
- Интерфейс переведён из wireframe в первый фирменный визуальный стиль MMT

## Статус

Это интерактивный прототип. Некоторые даты, проценты готовности, результаты и часть интерфейсных текстов демонстрационные и не должны использоваться как актуальная информация о поступлении. В итоговом продукте официальные данные вузов будут храниться по годам с датой проверки и источником.
