# MMT ДВИ

Прототип приложения для подготовки абитуриентов к поступлению на направления журналистики и к дополнительным вступительным испытаниям (ДВИ).

## Сейчас

- Wireframe: v0.2
- Главная навигация: Главная / Вузы / Подготовка / Портфолио / Профиль
- Есть возврат на предыдущий экран
- Тестовый вуз: СПбГИКиТ
- Реализованы демонстрационные сценарии выбора вуза, подготовки, задания, разбора, портфолио и календаря

## Статус

Это интерактивный прототип. Данные, даты, проценты готовности и часть интерфейсных текстов пока демонстрационные и не должны использоваться как актуальная информация о поступлении.
