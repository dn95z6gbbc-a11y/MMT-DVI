# MMT ДВИ

Интерактивный прототип приложения для подготовки абитуриентов к поступлению на направления журналистики и к дополнительным вступительным испытаниям (ДВИ).

## Сейчас

- Версия прототипа: v0.4.2
- Тестовый вуз: СПбГИКиТ
- Полный учебный цикл: урок → пример → упражнение → самостоятельная работа → разбор → исправление → повторная сдача
- Вузовская подготовка запускается только после добавления вуза в личный план; до этого можно изучить требования и посмотреть демо
- Авторизация в интерфейсе показана как будущий набор вариантов: телефон / VK / e-mail / Telegram
- В профиле есть отдельный вход в индивидуальную подготовку
- В блок «Об авторе» добавлены фотография Олега Мушкова и расширенная профессиональная биография
- Заложен раздел видеоотзывов учеников: Злата (Пенза), Кирилл (Ростов), Эльвира (Самара), Настя (Тобольск), Женя (Москва), Маша (Краснодар)
- Саша в этот набор отзывов не включена
- Портфолио развивается в двух направлениях: хранение работ + рекомендации по оформлению итоговой творческой папки

## Статус

Это прототип. Некоторые даты, проценты готовности, результаты и интерфейсные данные демонстрационные и не должны использоваться как актуальная информация о поступлении.

## Ближайший roadmap

1. Тестирование UX на абитуриентах и выпускниках подготовки
2. Реальные материалы MMT вместо демо-контента
3. МПГУ и РАНХиГС как дополнительные тестовые модели ДВИ
4. История устных ответов и сравнение прогресса
5. Загрузка и оформление видеоотзывов выпускников подготовки
6. Модель данных и админка
7. После стабилизации ключевых сценариев — Android-приложение
