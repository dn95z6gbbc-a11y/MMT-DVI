# MMT ДВИ

Интерактивный прототип приложения для подготовки абитуриентов к поступлению на направления журналистики и к дополнительным вступительным испытаниям (ДВИ).

## Сейчас

- Версия прототипа: v0.10
- Четыре модели вузов: СПбГИКиТ, МПГУ, РАНХиГС и ГИТР
- СПбГИКиТ: письменная работа + коллоквиум + портфолио
- МПГУ: свободный творческий текст; неофициальные примеры прошлых заданий маркируются отдельно
- РАНХиГС: программа ДВИ лета 2026, письменное тестирование; тренировочный банк ещё будет содержательно дорабатываться
- ГИТР: программа ДВИ 2026 по 42.03.02 «Журналистика», профиль «телевидение и радио» — коллоквиум, эссе и творческая папка

## Учебное ядро

- Углублённый модуль «Новости»: теория, интерактивные упражнения, самостоятельная работа, разбор и повторная сдача
- Центр пробных ДВИ, слабые места и следующий маршрут
- Медиасреда и повестка: две колонки СМИ/журналисты → рейтинги → медиаоблака → медиарацион 5+5 → региональный контур → учебная повестка
- Последовательный повесточный маршрут: следующий шаг открывается после выполнения предыдущего
- Универсальная база собеседования MMT + отдельные режимы ГИТРа и СПбГИКиТ
- Симуляции собеседования на 5 или 10 вопросов с уточнениями и историей попыток

## v0.10 — инфраструктурный апгрейд

### 1. Единая модель университетов

Введён единый реестр `MMT_UNIVERSITIES`. У каждого вуза одна структура данных:
- идентификатор и экран
- город
- образовательная программа
- версия / приёмная кампания
- статус наполнения данных
- источник
- модель и форматы ДВИ
- наличие портфолио
- бюджет / стоимость, если они уже внесены
- состояние «в плане»
- календарные требования

Каталог, сравнение, Главная и календарь читают данные из одного реестра. Это задел на добавление новых вузов без ручного дублирования одной и той же информации по разным экранам.

Старые подробные вузовские экраны пока сохранены. На них добавлен унифицированный «паспорт программы» со статусом данных, кампанией, форматом ДВИ и источником.

### 2. Каталог и сравнение вузов 2.0

Добавлен новый единый каталог:
- поиск по вузу, городу, программе и формату
- фильтр по Москве / Санкт-Петербургу
- фильтр по типу ДВИ: собеседование, письменная работа, тест, портфолио
- режим «только в моём плане»
- одинаковая структура карточек
- свободный просмотр вуза без добавления в план
- добавление / удаление из плана прямо из каталога
- сравнение до трёх программ одновременно

Сравнение не заполняет отсутствующие поля догадками: если стоимость, бюджет или другой показатель ещё не внесены, интерфейс так и пишет «не внесено».

### 3. Главная как диспетчер

На Главную добавлен динамический блок «Следующее действие». Он выбирает следующий системный шаг по текущему состоянию прототипа, например:
- нет вузов в плане → выбрать цель
- не собрана медиакарта → продолжить медиасреду
- выбран вуз с собеседованием, но нет полной симуляции → пройти её
- не завершена базовая практика новостей → вернуться к ней
- базовые входные шаги выполнены → перейти к диагностике слабых мест

Также Главная показывает выбранные цели и короткий список того, что требует внимания: медиарацион, портфолио, собеседования, неподтверждённые даты кампаний.

### 4. Календарь и дедлайны 2.0

Календарь теперь строится от вузов, которые реально добавлены в личный план.

Разделены три типа дат:
1. актуальные / относительные требования, которые уже есть в базе;
2. архив кампании 2026 — явно маркируется как архив и не переносится автоматически на следующий год;
3. личные даты пользователя — консультации, дедлайн черновика, отправка портфолио и другие собственные задачи.

Для ГИТРа внесено относительное требование программы 2026: творческая папка отправляется не менее чем за 3 дня до экзамена. Когда будет внесена дата экзамена конкретной кампании, модель сможет рассчитать крайний срок.

Для архивных дат СПбГИКиТ интерфейс специально предупреждает, что их нельзя использовать как даты следующей приёмной кампании.

Пользователь может:
- отметить действие выполненным
- включить демо-напоминание
- добавить собственную дату
- связать личную дату с вузом из своего плана

## Принцип данных

Формальная информация о поступлении не должна автоматически переноситься из одной кампании в другую. Если новая дата, стоимость, проходной балл или число мест ещё не подтверждены, значение остаётся пустым / «не внесено».

Примеры МПГУ, полученные от ученицы, не маркируются как официальный источник. РАНХиГС маркируется как программа ДВИ лета 2026. Для ГИТРа используется загруженная программа 2026.
